# Trading Project

This repository contains a research-oriented XAUUSD M5 trading workflow.

## Purpose
- Explore historical market structure and signal ideas.
- Run offline research and backtests.
- Keep MT5 integration isolated and optional.

## Setup
1. Create and activate a Python environment.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the research entry point:
   ```bash
   python main.py
   ```

## Notes
- This project is for research and experimentation only.
- No live trading is performed by the repository workflow.
- MT5 integration remains optional and should not be used for live orders.
